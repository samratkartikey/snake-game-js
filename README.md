# 🐍 Snake Game

A classic Snake Game built using **HTML**, **CSS**, and **Vanilla JavaScript**.

This project was created as part of my frontend development learning journey to strengthen my understanding of JavaScript fundamentals through hands-on practice.

---


## ✨ Features

- 🎮 Keyboard Controls
- 🐍 Dynamic Snake Movement
- 🍎 Random Food Generation
- 📈 Score Counter
- 🏆 High Score using Local Storage
- ⏱️ Live Timer
- 🔄 Restart Game
- 💥 Wall Collision Detection
- 📱 Responsive Layout

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- DOM Manipulation
- Local Storage
